# 专注模式

在「设置」中维护长期网站名单，点击「开始专注」后选择 25 / 45 / 60 / 90 分钟或自定义 1–1440 分钟。默认匹配所填域名及其子域名。专注期间不能删除网站、重新开始、暂停或缩短时间，只允许添加和延长；剩余时间最多 24 小时。到期自动解除本次专注限制，名单保留，内置成人网站防护不受影响。总览和菜单栏显示剩余时间。

## 执行与持久化

- 复用 `midogFilter` 系统扩展，注册 `group.com.xx.midog.focus` XPC 服务。App 和扩展互相验证签名标识及开发者 Team；仅 Debug 临时签名允许没有 Team 的开发构建。
- 扩展串行处理请求，校验只能追加/延长的规则，并将状态原子写入 `/Library/Application Support/midog-focus/state.json`。目录要求 root 持有且其他用户不可写；App 不直接写此文件。状态损坏会报告启动失败，不会默默重置为未开始。
- 使用持久化的绝对结束时间；休眠、退出 App、停止代理、重启电脑都不重新计时。系统过滤对每条有域名的新连接独立检查到期时间。系统扩展运行时记录连接关闭事件，开始或追加名单时更新已跟踪连接的拦截决定。
- 扩展维护 `domains.list`，专注域名进入 mihomo 的 `__MIDOG_FOCUS` 文件规则集，排在用户分流规则之前。扩展通过本机带密钥的 controller 刷新名单、关闭匹配的代理连接，并在到期后自动清空专注规则；此过程不依赖 UI 存活，代理同步可能有数秒延迟。
- 专注 controller 凭据仅保存在 root 可读的 `proxy.json`，限定本机地址，并禁止 HTTP 重定向。代理关闭时系统域名过滤继续工作；内核重新启动会读取当前名单。

## 升级

重新构建并安装签名的 App，批准系统扩展更新和内容过滤。旧系统扩展不提供专注接口，页面会显示未连接，不能假装开始专注。

已安装的旧代理服务需要在设置的「内核」区域点击一次「更新代理支持」，由原有管理员授权流程重启并更新 launchd 服务。新增的 `SAFE_PATHS` 仅允许 mihomo 读取专注目录。未安装内核的用户，下次首次启动时自动使用新配置。

## 验证

无管理员权限的检查：

```sh
xcrun swiftc midog/Core/FocusState.swift midog/Core/Models.swift midog/Core/JSONValue.swift midog/Core/SubscriptionParser.swift midog/Core/ConfigGenerator.swift tests/FocusCheck.swift -o /tmp/midog-focus-check
/tmp/midog-focus-check
python3 tests/FocusProxyCheck.py
```

第一项覆盖域名校验、重复项、活跃期间删除/重启/缩短的拒绝、延长上限、持久化、到期边界、损坏状态不覆盖、代理规则优先级。第二项只在临时目录启动项目内置 mihomo，不安装服务、不启用 TUN、不改系统代理，验证真实流量的拦截、子域名、动态追加、内核重启和规则解除。

安装签名扩展后的实机验收：

1. 先更新系统过滤；如果出现代理升级提示，完成更新。确认设置中显示专注服务已连接。
2. 添加可正常访问的网站和其子域名，设定 1 分钟专注，确认访问失败；不相关域名保持可用。
3. 专注时追加第二个网站，确认新访问及已跟踪连接被拦截；删除入口消失，再次开始和缩短请求在扩展端被拒绝。
4. 强制结束 midog，停止代理内核，在浏览器直连访问名单网站，确认系统过滤继续拦截。重新打开 App，确认结束时间未重置。
5. 另一次 1 分钟专注中退出 App，等待到期后重试。分别验证浏览器直连和经过代理两种路径解除限制，成人网站防护保持有效。
6. 用较长时长验证休眠与重启：尚未到期时继续拦截，超过结束时间后解除，网站名单仍然保留。

## 边界

沿用现有系统过滤的域名可见性限制：无法取得域名的连接不能仅凭这一层可靠匹配网站，代理流量由 mihomo 规则补充。已下载到浏览器的页面内容不会被清除，也不会替换为自定义拦截页。本功能没有新增防修改系统时间机制，也不能阻止管理员主动停用系统过滤或卸载扩展。
